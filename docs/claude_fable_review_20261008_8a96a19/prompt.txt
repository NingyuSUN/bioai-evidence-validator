0095 def parse_genomic_hgvs(text: str) -> tuple[str, list[Edit]]:
0096     """Fully consume absolute RefSeq g. substitutions/del/dup/inv/ins/delins.
0097 
0098     Compound alleles support semicolon-separated non-overlapping edits on one
0099     accession. Phase and HGVS 3-prime normalization are not inferred. N[length]
0100     keeps its length, with unknown bases. Redundant historical deletion suffixes
0101     are accepted for arithmetic only and explicitly require nomenclature review.
0102     """
0103     if any(c.isspace() for c in text) or text.count("(") != text.count(")") or text.count("[") != text.count("]"):
0104         raise VariantProblem("BEV024", "HGVS has whitespace or unbalanced delimiters.")
0105     if re.match(r"N[CG]_\d+(?:\.0)?:", text):
0106         raise VariantProblem("BEV024", "Genomic HGVS requires an explicit positive accession version.")
0107     head = re.fullmatch(r"(N[CG]_\d+\.[1-9]\d*):([cgmnpr])\.(.+)", text)
0108     if head is None:
0109         # Valid HGVS may have transcript/genomic combinations or other accession
0110         # families. Recognize these as outside this subset, not invalid biology.
0111         if re.match(r"[A-Z][A-Z0-9_().]*:[cgmnpr]\.", text) and text.count("(") == text.count(")"):
0112             raise VariantProblem("BEV015", "Reference or notation is outside the supported RefSeq genomic subset.")
0113         raise VariantProblem("BEV024", "Missing versioned accession/coordinate prefix, whitespace, or malformed HGVS.")

0115         raise VariantProblem("BEV015", "Only absolute genomic g. coordinates are checked; transcript/protein mapping is unavailable.")

0117     parts = body[1:-1].split(";") if body.startswith("[") and body.endswith("]") else [body]
0118     edits = []

0001 """Source grounding: recompute from pinned source snapshots what a record only asserts.
0002 
0003 The engine trusts supplied metadata. A grounder moves that trust boundary toward the source: given
0004 the exact source bytes, it recomputes what the record claims (hashes, identifiers, derived evidence)
0005 and reports disagreements as findings. Grounding is optional, offline and deterministic; without
0006 grounders, validation and its reports are unchanged.
0007 
0008 Rule codes (all apply to every requested use):
0009   BEV014 error   source bytes in the snapshot store do not match the record's frozen hash
0010   BEV015 review  the source cannot confirm it: bytes unavailable, or an item the grounder cannot recompute
0011   BEV016 error   a cited identifier does not exist in the source
0012   BEV017 error   the record disagrees with what the source says
0013   BEV018 review  the source holds evidence the record leaves out
0014   BEV019 error   the cited source is retracted
0015   BEV022 review  a semantic cue suggests the quote is misread (see `semantic`)
0016   BEV023 error   a cited identifier is obsolete, withdrawn or not its current name (see `identifiers`)
0017   BEV024 error   a cited identifier is malformed, or of the wrong kind for its place (see `identifiers`)
0018   BEV025 review  a pinned reference resource contradicts the claim or its evidence (see `crosscheck`)
0019   BEV026 review  measurements contradict the ontology definition of the claimed term (see `definitions`)

0001 # Canine preflight: branch preparation before full-panel integration
0002 
0003 `canine-preflight` is additive on the local `canine-panel-validation` branch.
0004 The existing `canine-panel` and `canine-capture` commands and their stored examples
0005 retain their contracts. The new command uses those same pinned reference formats.
0006 
0007 ```bash
0008 bioevidence canine-preflight examples/canine_preflight/panel.json \
0009   --snapshot-dir examples/canine_panel/sources --output /tmp/canine-preflight.json
0010 ```
0011 
0012 The bundled example has six historical source cases, not the current project's
0013 629 events. It deliberately requests target equivalence without supplying target
0014 VCF alleles: that missing work remains visible. Expected exit is 2 (review).
0015 The legacy six-event source snapshots are reused without copying or changing them.
0016 
0017 ## Purpose and input
0018 
0019 The public entry is `validate_canine_preflight(document, store)`. Input has:
0020 
0021 - `format_version: canine-preflight-1`, `taxon: NCBITaxon:9615`;
0022 - `catalogue`: every expected event, each with `id` and nonempty `required_checks`;
0023 - optional `panel`: an existing `canine-panel-1` document for executable events;
0024 - optional `allele_requests`: per-event requests with `event_id` and one or both
0025   of `source_mutant_snapshot_sha256` and `target_variant`;
0026 - optional `previous_report_sha256`: exact bytes of a prior preflight report.
0027 
0028 No coordinates or reference names need to be invented for unresolved events:
0029 include them in `catalogue` and omit them from `panel`. All catalogue events are
0030 returned. Duplicate IDs, panel events outside the catalogue, requests without
0031 panel events, unknown checks and unsupported readiness assertions are input errors.
0032 Catalogue completeness is relative to the supplied list; this command cannot
0033 prove that the literature or project inventory is exhaustive.
0034 
0035 Checks are `source_reference`, `allele_reconstruction`, `target_equivalence`,
0036 `capture_specificity`, `dosage`, `phase`, and `assay_performance`. The last four
0037 are explicitly **not implemented** here and return `not_assessed`. Existing
0038 specialized capture scripts and `canine-capture` are still separate; their
0039 reports are not imported as proof of these checks. A missing required check
0040 prevents the event and aggregate report from being `verified`.
0041 
0042 ## Complete allele replay
0043 
0044 All supported genomic edits are applied in original source coordinates to the
0045 entire pinned source slice, preserving unchanged flanks and intervening bases.
0046 Supported operations are substitutions, deletions, tandem duplications,
0047 inversions, insertions, deletion-insertions and nonoverlapping combinations.
0048 An insertion goes after its left flank. Supplied compound `event_ref`/`event_alt`
0049 are compared with the outer event span, including unchanged intervening bases.
0050 
0051 Unknown inserted bases (`N[length]`), ambiguous reference bases, overlapping edits,
0052 repeat-count notation, transcript coordinates and unsupported forms remain under
0053 review. Unknown payloads are never expanded into apparently recovered sequence.
0054 Reconstructing a proposed compound allele does not verify physical phase.
0055 Source corrections, source holds and original WT-context mismatches remain visible.
0056 
0057 `source_mutant_snapshot_sha256` binds **exact uppercase raw ACGT sequence bytes**,
0058 without FASTA header or trailing newline, spanning the entire source context.
0059 Its content is compared with the freshly reconstructed string, not only its hash.
0060 It is a supplied candidate, not evidence of an observed mutant sample.
0061 
0062 `target_variant` has `chrom`, one-based `pos1`, and nonempty uppercase ACGT `ref`
0063 and `alt` representing one biallelic VCF edit on the forward target reference.
0064 The command checks target REF, applies the edit to the full target context, orients
0065 that context, and compares it with the full reconstructed source mutant. Symbolic,
0066 multiallelic, empty and ambiguous alleles are unsupported. Source and target WT
0067 contexts must first pass the existing complete-context check. VCF normalization
0068 is not performed; equivalent normalized or unnormalized edits may compare equal.
0069 
0070 ## Prior-report applicability
0071 
0072 Every event fingerprints its catalogue requirements, full source event, allele
0073 request, and referenced snapshot specifications (including assembly, accession,
0074 query key and whole-reference hash). Unrelated events do not invalidate that
0075 fingerprint. The report also hashes the replay implementation and reference loader.
0076 Changes in these dependencies invalidate applicability. Missing or invalid current
0077 reference bytes prevent a historical passing report from claiming applicability.
0078 
0079 `same_inputs_and_implementation` means the pinned report claims the same inputs
0080 and implementation. It does **not** authenticate the old producer or its result.
0081 All currently supported inexpensive checks are recomputed on every invocation;
0082 `prior_results_used_to_skip_checks` is always false. No older status can promote
0083 an event. Reuse of expensive server calculations is a later adapter concern and
0084 must bind the actual execution evidence, scope and applicable implementation.
0085 
0086 ## Output, limits and integration acceptance
0087 
0088 Per-check statuses are `verified`, `review_required`, `rejected`, `not_assessed`.
0089 Per-event and aggregate statuses use the first three; required `not_assessed`
0090 checks yield `review_required`. Counts include all catalogue events, with the
0091 executable panel count reported separately. Exit codes are 0 for these engineering
0092 checks verified, 2 for review, 1 for contradictions and 3 for invalid input/configuration.
0093 
0094 Assay validation, ordering, reporting and evidence admission remain false. The
0095 command does not measure breed accuracy, authenticate whole-reference receipts,
0096 establish disease causality, freeze loci, or replace laboratory validation.
0097 
0098 Before production integration, the canine adapter must supply the full current
0099 event catalogue and correct route-specific required checks, export actual pinned
0100 reference slices and target edits, preserve unresolved events and original evidence,
0101 and reconcile all returned IDs. This branch development does not change the canine
0102 current-draft pointers or declare those 629 events newly validated.
0103 
0104 Engineering controls include hand-derived sequences for each operation, reversed
0105 compound order, intervening bases, reverse strand, wrong REF and mutant payload,
0106 unknown inserted length, duplicate/orphan events, missing evidence, old-report
0107 compatibility, changed source holds, and CLI input overwrite protection. These
0108 controls and reused real cases provide software evidence, not independent clinical
0109 labels or an estimate of sensitivity/specificity.
0110 
0111 Final branch validation receipts: [2026-10-08 checks](canine_preflight_checks_20261008/README.md).
